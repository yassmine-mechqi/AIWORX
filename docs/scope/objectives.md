# 1. Objectifs du projet

## 1.1 Présentation

AIWORX est une plateforme numérique de services destinée initialement au marché marocain B2B.

Le projet a pour objectif de créer un environnement numérique permettant aux entreprises clientes de trouver des prestataires de services vérifiés et de gérer l'ensemble du processus de réalisation d'une prestation, depuis l'expression du besoin jusqu'à l'évaluation finale.

AIWORX doit également assurer un rôle de confiance et d'accompagnement à travers la qualification des besoins, la vérification des prestataires, le suivi des prestations, le contrôle qualité et la traçabilité des opérations.

Le périmètre initial du projet comprend :

* un Website public ;
* une Marketplace ;
* un Back-office AIWORX.

L'horizon initial prévu pour le projet est de 4 à 6 mois.

---

## 1.2 Objectif principal

L'objectif principal d'AIWORX est de mettre en place une plateforme de services vérifiés permettant de connecter des entreprises clientes à des prestataires qualifiés tout en sécurisant et structurant le cycle complet d'une prestation.

La plateforme doit permettre de gérer le processus suivant :

1. création du compte ;
2. création du besoin ;
3. qualification du besoin ;
4. recherche et matching des prestataires ;
5. réception et gestion des offres ;
6. comparaison et négociation ;
7. sélection du prestataire ;
8. contractualisation ;
9. signature ;
10. financement ;
11. exécution de la mission ;
12. contrôle des livrables ;
13. corrections ;
14. validation finale ;
15. reversement ;
16. évaluation.

---

## 1.3 Objectifs fonctionnels

Le projet doit permettre aux entreprises clientes de :

* créer et gérer leur compte ;
* présenter leur organisation ;
* créer un besoin ;
* décrire leurs objectifs et contraintes ;
* joindre les documents nécessaires ;
* être accompagnées dans la qualification du besoin ;
* obtenir une spécification structurée ;
* rechercher ou recevoir des recommandations de prestataires ;
* recevoir des offres ;
* comparer les offres ;
* demander des clarifications ;
* négocier les conditions ;
* sélectionner un prestataire ;
* gérer la contractualisation ;
* suivre l'exécution de la mission ;
* suivre les jalons ;
* contrôler les livrables ;
* demander des corrections ;
* valider les livrables ;
* réaliser la validation finale ;
* évaluer la prestation.

Le projet doit permettre aux prestataires de :

* créer un compte ;
* compléter leur profil ;
* présenter leurs compétences ;
* renseigner leurs catégories de services ;
* présenter leurs références et leur portfolio ;
* fournir les informations nécessaires à leur vérification ;
* suivre leur processus de qualification ;
* recevoir des opportunités correspondant à leur profil ;
* soumettre des offres ;
* suivre les offres proposées ;
* participer aux échanges nécessaires à la clarification du besoin ;
* suivre les missions obtenues ;
* déposer les livrables ;
* effectuer les corrections demandées ;
* suivre le processus de validation ;
* recevoir les reversements selon les conditions prévues.

Le projet doit permettre aux équipes AIWORX de :

* vérifier les prestataires ;
* contrôler les informations fournies ;
* accompagner la qualification des besoins ;
* intervenir dans la spécification ;
* superviser les projets ;
* assurer le contrôle qualité ;
* suivre les opérations financières ;
* gérer les situations nécessitant une intervention ;
* consulter les informations nécessaires à l'administration de la plateforme ;
* assurer la traçabilité des opérations importantes.

---

## 1.4 Objectifs liés à la qualification des prestataires

AIWORX doit permettre de mettre en place un processus de qualification des prestataires.

Ce processus doit permettre notamment de recueillir et vérifier :

* les informations d'identité ;
* les informations légales ;
* les informations professionnelles ;
* les compétences ;
* les références ;
* le portfolio ;
* les certifications ou badges disponibles ;
* les résultats des éventuels tests de compétences.

Le processus doit également permettre une validation manuelle par AIWORX lorsque celle-ci est nécessaire.

L'objectif est de disposer d'informations suffisamment structurées sur les prestataires afin de permettre leur présentation et leur mise en relation avec les besoins correspondants.

---

## 1.5 Objectifs liés à la qualification des besoins

AIWORX doit permettre aux entreprises de transformer une expression initiale du besoin en une demande suffisamment structurée pour être proposée aux prestataires.

La qualification doit permettre de prendre en compte notamment :

* le contexte ;
* les objectifs ;
* la cible ;
* le périmètre ;
* les livrables ;
* les contraintes ;
* le budget ;
* le calendrier ;
* les critères d'acceptation ;
* les dépendances ;
* les exclusions ;
* les exigences de confidentialité.

La plateforme doit pouvoir utiliser différents modes de collecte du besoin, notamment :

* formulaire guidé ;
* description libre ;
* fichiers ;
* questionnaire intelligent ;
* import d'un cahier des charges ;
* entretien avec un conseiller AIWORX.

---

## 1.6 Objectifs liés à l'intelligence artificielle

L'intelligence artificielle doit être utilisée comme un outil d'assistance dans plusieurs étapes du processus AIWORX.

Les principaux objectifs identifiés sont :

* assister la qualification du besoin ;
* structurer les informations fournies par le client ;
* assister la création de la spécification ;
* contribuer au matching entre les besoins et les prestataires ;
* assister l'analyse des offres ;
* générer des synthèses utiles à la comparaison ;
* assister certaines opérations de contrôle qualité.

L'utilisation de l'intelligence artificielle doit rester intégrée au processus métier défini par AIWORX.

Les étapes nécessitant une validation humaine doivent conserver l'intervention des utilisateurs ou des équipes AIWORX concernées.

---

## 1.7 Objectifs liés à la mise en relation

AIWORX doit faciliter la mise en relation entre les entreprises clientes et les prestataires correspondant à leurs besoins.

Le système doit permettre plusieurs modes de sourcing :

* publication ouverte contrôlée ;
* recommandation AIWORX ;
* recherche dans le catalogue ;
* attribution directe ;
* service prédéfini.

L'objectif est de fournir aux entreprises un processus structuré permettant d'identifier des prestataires correspondant aux caractéristiques du besoin.

---

## 1.8 Objectifs liés aux offres

La plateforme doit permettre aux prestataires de présenter des offres structurées.

Les offres doivent pouvoir contenir les informations nécessaires à leur analyse et à leur comparaison, notamment :

* compréhension du besoin ;
* méthodologie ;
* étapes ;
* livrables ;
* critères d'acceptation ;
* références pertinentes ;
* questions ;
* prix ;
* délai ;
* jalons ;
* dépendances ;
* conditions ;
* validité de l'offre ;
* disponibilité pour le démarrage.

L'objectif est de disposer d'offres suffisamment structurées pour permettre leur comparaison dans un cadre commun.

---

## 1.9 Objectifs liés à la contractualisation

AIWORX doit permettre de structurer le passage entre la sélection d'un prestataire et le démarrage de la mission.

Les objectifs sont notamment de :

* formaliser les conditions convenues ;
* gérer la version contractuelle ;
* permettre la signature ;
* conserver la version signée ;
* assurer la traçabilité des modifications importantes.

Une spécification validée peut servir de référence contractuelle lorsque le processus prévu le nécessite.

Les modifications importantes après validation doivent pouvoir être gérées dans un cadre permettant de prendre en compte leurs impacts sur le prix et le délai.

---

## 1.10 Objectifs liés au financement

AIWORX doit intégrer les opérations financières nécessaires au cycle de la prestation.

Les objectifs sont notamment de permettre :

* le financement de la prestation ;
* le suivi des opérations financières ;
* le traitement des reversements ;
* la gestion des éventuels remboursements ;
* le suivi des situations nécessitant un blocage ou une intervention.

Les opérations financières importantes doivent être enregistrées et traçables.

---

## 1.11 Objectifs liés au suivi des missions

AIWORX doit permettre de suivre une prestation pendant toute sa phase d'exécution.

Le suivi doit permettre notamment de gérer :

* la mission ;
* les jalons ;
* les livrables ;
* les différentes versions des livrables ;
* les contrôles ;
* les corrections ;
* la validation finale.

L'objectif est de fournir une visibilité structurée sur l'avancement de la prestation et sur les éléments nécessaires à sa validation.

---

## 1.12 Objectifs liés à la qualité

AIWORX doit intégrer un processus permettant de contrôler la qualité des prestations.

Le contrôle qualité doit permettre de vérifier les livrables par rapport aux éléments attendus.

Lorsque des éléments ne sont pas conformes, le processus doit permettre :

* d'identifier les éléments concernés ;
* de demander une correction ;
* de recevoir une nouvelle version ;
* de conserver les différentes versions ;
* de poursuivre le processus jusqu'à la validation.

L'objectif est d'assurer un suivi structuré de la qualité et des corrections.

---

## 1.13 Objectifs liés à la confiance et à la sécurité

AIWORX doit fournir un environnement permettant aux utilisateurs d'effectuer les principales opérations de la plateforme dans un cadre sécurisé.

Les objectifs comprennent notamment :

* authentifier les utilisateurs ;
* gérer les rôles et permissions ;
* contrôler l'accès aux informations ;
* protéger les données ;
* protéger les documents et fichiers ;
* préserver la confidentialité des informations sensibles ;
* tracer les opérations importantes ;
* assurer la sécurité des opérations financières.

La sécurité doit être prise en compte de manière transversale dans l'ensemble de la plateforme.

---

## 1.14 Objectifs liés à la traçabilité

La plateforme doit conserver les informations nécessaires au suivi des actions importantes réalisées pendant le cycle de vie d'une prestation.

La traçabilité doit notamment concerner :

* les actions des utilisateurs ;
* les changements importants ;
* les versions des documents ;
* les étapes du processus ;
* les opérations financières ;
* les validations ;
* les corrections ;
* les événements importants du système.

L'objectif est de pouvoir reconstituer l'historique nécessaire au suivi et à l'administration de la plateforme.

---

## 1.15 Objectifs liés au Back-office

Le Back-office doit fournir aux équipes AIWORX les moyens nécessaires pour administrer et superviser la plateforme.

Les objectifs comprennent notamment :

* administrer les utilisateurs ;
* administrer les organisations ;
* gérer les prestataires ;
* traiter les vérifications ;
* superviser les besoins ;
* suivre les prestations ;
* superviser la qualité ;
* suivre les opérations financières ;
* gérer les litiges ;
* consulter les journaux d'audit ;
* gérer les opérations nécessitant une intervention interne.

Les accès au Back-office doivent être contrôlés selon les rôles et permissions définis.

---

## 1.16 Objectifs liés à l'expérience utilisateur

La plateforme doit permettre aux différents acteurs de suivre un parcours structuré correspondant à leur rôle.

Les informations et fonctionnalités présentées doivent être adaptées au contexte de l'utilisateur :

* entreprise cliente ;
* prestataire ;
* conseiller AIWORX ;
* expert qualité AIWORX ;
* administrateur financier.

Le Website public doit être disponible en français et en anglais.

---

## 1.17 Objectifs métier

AIWORX doit permettre de structurer et sécuriser le marché des services numériques B2B en facilitant la relation entre entreprises clientes et prestataires.

Les objectifs métier sont notamment :

* structurer la demande des entreprises ;
* faciliter l'identification de prestataires ;
* améliorer la qualification des prestataires ;
* structurer les offres ;
* faciliter la comparaison ;
* sécuriser la contractualisation ;
* suivre l'exécution ;
* contrôler la qualité ;
* organiser les opérations financières ;
* conserver une traçabilité du processus ;
* fournir un cadre de confiance entre les différents acteurs.

---

## 1.18 Objectifs d'évolution

Le projet doit permettre une évolution progressive de la plateforme.

L'architecture et l'organisation fonctionnelle doivent permettre d'ajouter ou de faire évoluer les fonctionnalités sans remettre en cause l'ensemble du système.

Les évolutions futures peuvent notamment concerner l'extension du catalogue de services, l'évolution des mécanismes de matching, l'amélioration des fonctions d'intelligence artificielle ou l'extension du marché couvert.

Ces évolutions ne font pas partie des fonctionnalités détaillées du périmètre initial lorsqu'elles ne sont pas définies dans le cahier des charges.

---

## 1.19 Résultat attendu

À l'issue de la réalisation du projet, AIWORX doit disposer d'une plateforme permettant de gérer de manière structurée le cycle complet d'une prestation de services B2B.

Le système doit permettre :

* aux entreprises clientes de formuler et gérer leurs besoins ;
* aux prestataires de présenter leurs compétences et de proposer des offres ;
* à AIWORX d'assurer la qualification, l'accompagnement et la supervision ;
* aux différents acteurs de suivre les étapes du projet ;
* de gérer les contrats et signatures ;
* de gérer les opérations financières ;
* de contrôler la qualité ;
* de gérer les corrections ;
* de réaliser la validation finale ;
* d'effectuer les reversements ;
* de réaliser les évaluations ;
* de conserver une trace des opérations importantes.

Ces objectifs constituent la base fonctionnelle du projet et servent de référence pour la définition du périmètre, de l'architecture, des workflows, de la base de données et du Backend.
